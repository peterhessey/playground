> Just-in-time compilation tends to be the fastest way to implement dynamically typed languages, but not all of them use it. What reasons are there to not JIT?

- You don't catch many errors until the code is already running
- This could potentially lead to security risks?
- It also sounds rly rly hard to implement and maintain

Asking Claude and he widely agrees with this and adds the following points:

- Memory consumption larger than compiled languages
- Non-determinism
- debugging is a pain!
