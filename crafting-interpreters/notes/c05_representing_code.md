Some key terms

- Regular language - what we defined before for the tokenizer/scanner. These don't allow arbitrary recursion.
- Context-free grammars (CFGs) - next level up from a regular language, these do allow arbitrary recursion!
- The expression problem - the conflict between functional and OOP languages, where in it is hard to add new objects and new functionality in each paradigm, respectively
